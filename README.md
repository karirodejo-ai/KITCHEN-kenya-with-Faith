# KITCHEN kenya with Faith

HTML, CSS and vanilla JavaScript. No framework or build step.

Open index.html or deploy this folder to any static web host. Images and fonts are bundled locally.

Design rebuilt from the supplied Option B stylesheet and scripts. Uses the uploaded family-table hero, with the original GitHub site's 20 dishes, food photos, descriptions, prices, lunch set, story and contact information.

Checkout is a local demo order request only. It does not send an order or accept payment. Call Faith to confirm a real order.
